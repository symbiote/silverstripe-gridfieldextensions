# GridField extensions

A collection of components to extend the functionality of [`GridField`](api:SilverStripe\Forms\GridField\GridField), including inline editing, reordering, nested grids, improved searching, and configurable pagination.

## Installation

```bash
composer require symbiote/silverstripe-gridfieldextensions
```
